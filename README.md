# Hello World

Простой статический сайт «Hello, World!» — один файл `index.html` на чистом HTML, CSS и JavaScript, без зависимостей и сборки.

## Запуск

Просто откройте `index.html` в браузере, или поднимите локальный сервер:

```bash
python3 -m http.server 8000
```

и перейдите на http://localhost:8000
